## Content

`StepList` follows the [Collection Components API](collections?component=StepList). Use `id` on each `Step`.

```tsx render
"use client";
import {StepList, Step} from '@react-spectrum/s2/StepList';

const steps = [
  {id: 'account', name: 'Account'},
  {id: 'shipping', name: 'Shipping'},
  {id: 'payment', name: 'Payment'}
];

<StepList aria-label="Checkout" items={steps} defaultLastCompletedStep="account">
  {item => <Step id={item.id}>{item.name}</Step>}
</StepList>
```
